# EHDL 화면·명령·산출물

> 코드: `src/ehdl/gui/` — 메인 창 `main_window.py`, 패널 `panels.py`, 에디터 `editor.py`.
> FHDL 과 같은 구성(DSL 에디터 · 그래프 · 결과 · 진단 · 하단 콘솔)이고 공용 부품(로그 콘솔·진단 패널·편집 대화상자·
> 도면 렌더러·테마)을 재사용한다. 시작 화면에서 **EHDL** 을 고르거나 `python main.py --domain ehdl`.

## 화면

```
┌ DSL 에디터 ─┬ 계통 구성도 (단선결선도 = 그래프 에디터) ─┬ 노드 상세 ┐
├ 결과: 판정 · 설비 · 배선 · 시나리오 [검산 모드 / 기본설계 모드] ┬ 진단 ┤
└ 작업 로그 + 명령 입력 ┘
```

- **DSL 에디터**: 구문 강조, 오류 줄 표시, 문법 참조(?), 설비 추가(+) — 편집 300ms 뒤 자동 재해석(SPEC 원칙 8).
- **계통 구성도**: 전원 → 말단 트리, 반은 모선, IEC 60617 스타일 기호, 설비·배선마다 판정 ● 색(FAIL 빨강·UNKNOWN 주황·
  REVIEW 노랑·PASS 초록). 클릭 = 선택(주황 강조) → 노드 상세, 더블클릭 = 속성 편집, **오른쪽 클릭** = 속성 편집 ·
  판정 근거 보기 · 반 **접기/펼치기** · 아래에 배선·부하 연결 · 삭제. 접힌 반은 내부 판정까지 합친 색으로 표시.
- **노드 상세** (SPEC 7.2): 1 쉬운 설명(+용어 풀이) · 2 입력값 · 3 계산된 요구조건 · 4 실제 설계 규격 · 5 적합성 판정
  (식·적용 기준·**KEC 원문 발췌**(지식 DB)·기준 기본값·추정·필요 입력) · 6 선정 근거 · 7 설계자에게 확인할 질문 ·
  산정 근거 추적(하위 설비별 전류·전력).
- **결과**: 판정 표(대상·항목·요구·실제·사용률·판정), 설비(P·Q·S·최대 상전류·누적 전압강하), 배선, 시나리오별 전류,
  **단락·기동**(설비별 Ik'' 최대·최소·전동기 기여·차단용량·판정), **접지·수전**(고장보호·PE·본딩·수전 종합),
  **변경 영향**(해석할 때마다 직전 해석 대비 판정 악화·개선·값 변화 — 악화가 있으면 로그에 경고),
  **혼합(기존/신규)**(신규 부하 전·후 기존 설비 사용률·병목), **변경 이력**(저장 시점별 수정 내용·판정 변화).
  배선 탭에 **요구 단면적(지배 조건)**, 계통 구성도에 단면적 미입력 배선은 `요구 ≥ … ㎟`, 신규 설비는 `[신규]`.
  계통 구성도에도 모선·차단기마다 `Ik'' … kA / Icu … kA`, 왼쪽 아래 접지·등전위본딩 띠(접지 기호·본딩 굵기·판정 ●).
  **검산 모드** = 요구 vs 실제, **기본설계 모드** = 요구규격만. 행 클릭 → 노드 상세·그래프 선택.

## 메뉴·단축키

| 단축키 | 동작 |
|---|---|
| F5 / Ctrl+Enter | 해석 |
| Ctrl+Shift+N / Ctrl+O / Ctrl+S / Ctrl+Shift+S | 새 계통 / 열기(.ehd) / 저장 / 다른 이름으로 |
| Ctrl+Shift+E | 계통 구성도 내보내기 (PDF·SVG·DXF·PNG) |
| Ctrl+Shift+R | 검산 보고서 (PDF·HTML·CSV·JSON) |
| 파일 → 데모 열기 | `projects/ehdl_demo/main.ehd` |
| 파일 → 설계 분야 전환 | 시작 화면으로 (FHDL ↔ EHDL) |

## 명령 (하단 콘솔)

| 명령 | 예 |
|---|---|
| `add <종류> <id> [k=v ...]` | `add load M4 parent=PNL_A kind=motor rating=7.5kW basis=output efficiency=89% pf=0.84 phases=3` |
| `set <id> k=v [...]` (`k=-` 삭제) | `set PNL_B rated_current=125A` |
| `del <id>` | 설비 + 연결 배선 + 소속 참조 정리 |
| `link <A> <B> [k=v ...]` | `link CB_P1 P1 length=60m material=Cu size=25mm2` |
| `scenario <id> on=A,B [off=C]` | `scenario night off=PNL_A` |
| `why <id>` | 판정·식·기준(원문 쪽)·질문을 로그로 |
| `impact` | 직전 해석 대비 판정 변화 (설계 변경 영향) |
| `history [id]` | 저장 시점별 변경 이력 (id 를 주면 그 설비만) |
| `ls` | 설비·배선 목록 |
| `dwg [export <파일>]` | 계통 구성도 내보내기 (상대 경로 = .ehd 폴더 기준) |
| `report <파일.pdf\|html\|csv\|json>` | 검산 보고서 |
| `run` `save` `clear` `help` | |

## 산출물 (SPEC 12)

| | 내용 | 형식 |
|---|---|---|
| A 계통 구성도 | 단선결선도 + 판정 요약·FAIL 표·NOTES·표제란 | PDF·SVG·DXF·PNG (FHDL 도면 엔진 공유) |
| B 설비 요구규격표 | 요구조건·계산 근거·운전 조건 | 보고서 |
| C 설계 검산표 | 요구·실제·사용률·판정·적용 기준(원문 쪽) | 보고서 |
| D 운전 시나리오 분석표 | 시나리오별 정격 설비 사용률 | 보고서 |
| E 설계 근거 분석표 | 최대 예상·선정 규격·여유율·선정 근거 | 보고서 |
| F 발주자 검토 질문서 | 질문 + 계산 근거 | 보고서 |
| 병목 | FAIL 대상·조건·원인 부하·전원까지 경로 | 보고서 |
| 접지·고장보호 / 수전 종합 | 자동차단·PE·본딩 판정 · 설비용량·최대수요·수용률·계약전력·변압기 (SPEC 5.12) | 보고서 |
| 설계 변경 영향 | 직전 해석 대비 변화 (GUI 에서 내보내면 포함) | 보고서 |
| 혼합 모드 / 변경 이력 | 신규 부하 전·후 기존 설비 · 저장 시점별 수정 내용 | 보고서 |

보고서 `report.export_report`: JSON(전체 판정·근거) · CSV(표별 파일 `_B.csv` …) · HTML · PDF(A4 가로).
모든 행 첫 칸이 설비/배선 ID — 그래프 위치와 연결된다. 아이소메트릭 CAD 는 기본형 완성 후 추가(사용자 결정).
