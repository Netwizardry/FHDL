# 1. 프로젝트 개요

## 1.1 목적

본 프로젝트는 전력계통을 노드(Node)와 엣지(Edge)로 모델링하여 전기설비의 기본설계, 기존 설계 검산, 운전 조건 분석을 수행하는 소프트웨어를 개발하는 것이다.

전기공학의 복잡한 계산을 프로그램 내부에서 수행하고, 사용자는 장비의 제원, 연결 관계, 설치 조건을 입력하는 것만으로 설비의 요구규격과 설계 타당성을 확인할 수 있어야 한다.

**핵심 질문: "왜 이 전기설비는 이 규격으로 설계되어야 하는가?"**

프로그램은 단순히 적합·부적합을 판정하는 데 그치지 않고, 해당 설계값이 도출된 계산 근거를 사용자에게 제공한다.

## 1.2 기본 철학

1. 사용자는 전기설계 전문가일 필요가 없다.
2. 전문 계산은 결정론적 계산 엔진이 수행한다.
3. 모든 계산은 입력값과 적용 기준을 통해 재현 가능해야 한다.
4. 요구규격과 실제 선정규격은 독립적으로 관리한다.
5. 제조사, 상품명, 가격은 설계의 판단 기준이 아니다.
6. 과도한 설계와 부족한 설계를 모두 검토한다.
7. 계산에 필요한 정보가 없으면 추정값과 미확정 결과를 명시적으로 구분한다.
8. 설계 변경은 영향을 받는 계통의 재계산으로 이어진다.

## 1.3 개발 범위

### 포함

- 노드 기반 전력계통 구성
- 부하 및 수요전력 계산
- 분전반·배전반 구성
- 간선 및 분기회로 계산
- 전선 규격 산정
- 차단기 요구규격 산정
- 전압강하 계산
- 상별 전류 및 불평형 분석
- 동시운전 및 최대부하 분석
- 모터 기동 조건 분석
- 단락전류 계산
- 보호장치 동작 및 보호협조 검토
- 도체 열적 허용조건 분석
- 접지 및 보호도체 구성 검토
- 누전보호 및 서지보호 요구조건 확인
- 수전설비의 요구용량 산정
- 기존 설계와 계산 결과 비교
- 설계 근거 및 질문 생성
- 계산 결과 보고서 출력

### 제외

- 전기 CAD 도면 작성
- 실제 시공 상세도 작성
- 케이블 트레이 및 관로 상세 배치
- 자재 수량 적산
- 자재 가격 및 구매처 분석
- 노무비 및 공사비 계산
- 특정 제조사 제품 자동 구매·선정
- 건축 구조 및 공간 간섭 해석
- 조명 배치·조도 계산
- 전기설비 전체 분야를 포괄하는 통합 설계

외부 CAD의 배선 길이와 위치 데이터는 선택적으로 입력받을 수 있다.

# 2. 시스템의 기본 구조

## 2.1 노드 그래프

전력계통을 다음과 같이 표현한다.

**Node:** 전기적 기능을 가진 설비, 장치 또는 연결점

**Edge:** 노드 사이의 전력 전달, 도체 연결 또는 보호도체 연결 관계

예시:

```
[한전 공급점]
      │
   [수전설비]
      │
   [변압기]
      │
   [메인 배전반]
      │
 ┌────┴────┐
 │         │
[분전반 A] [분전반 B]
 │         │
[차단기]   [차단기]
 │         │
[모터]     [콘센트]
```

그래프는 전기계통의 논리적 구성과 계산 데이터를 동시에 보유한다.

초기 지원 대상은 단일 전원 기반 방사형 배전계통으로 한다.

## 2.2 계층적 노드

노드는 하위 그래프를 포함할 수 있어야 한다.

예를 들어 분전반은 외부에서 단일 노드로 표시되지만 내부를 펼치면 다음과 같은 구성이 나타난다.

```
[분전반 A]
     │
  [주차단기]
     │
   [모선]
     │
  ┌──┴──┐
  │     │
[분기1] [분기2]
  │     │
[장비1] [장비2]
```

상위 그래프에서 분전반은 단일 설비로 취급되며, 계산 시 내부 회로의 결과를 집계한다.

내부 그래프와 외부 그래프는 명확하게 정의된 전기적 연결 포트를 통해 연결한다.

계층의 깊이는 고정하지 않는다.

## 2.3 노드 분류

| 노드 종류   | 주요 역할               |
| ------- | ------------------- |
| 전원      | 공급전압·주파수·전원 임피던스 정의 |
| 수전설비    | 공급용량 및 수전 조건        |
| 변압기     | 전압 변환·정격·임피던스       |
| 배전반     | 상위 배전계통 집계          |
| 분전반     | 하위 회로 집계 및 분기       |
| 모선      | 다수 회로의 전기적 접속       |
| 일반 차단기  | 과전류·단락 보호           |
| 누전보호장치  | 잔류전류 감지 및 보호        |
| SPD     | 서지보호                |
| 부하      | 장비·모터·콘센트 등의 소비전력   |
| 접지·보호도체 | 보호도체 및 등전위 연결       |

차단기와 누전보호 기능이 하나의 실제 장치에 결합된 경우도 표현할 수 있어야 한다.

## 2.4 엣지 분류

엣지는 연결 관계 외에 실제 도체의 전기적 속성을 보유한다.

- 전력 케이블 및 배선
- 모선 연결
- 보호도체(PE)
- 접지 연결
- 등전위본딩 연결

각 엣지는 길이, 재질, 단면적, 도체 구성, 임피던스, 허용전류 등의 속성을 가진다.

전력 전달 경로와 접지·보호도체 경로는 서로 다른 연결 유형으로 모델링한다.

# 3. 데이터 모델

## 3.1 공통 노드 속성

모든 노드는 다음 속성을 가진다.

| 필드         | 설명            |
| ---------- | ------------- |
| ID         | 고유 식별자        |
| Type       | 노드 종류         |
| Name       | 사용자 지정 명칭     |
| Parent     | 상위 컨테이너 노드    |
| Ports      | 전기적 접속 포트     |
| Parameters | 사용자 입력 속성     |
| Required   | 계산된 요구조건      |
| Installed  | 실제 선정·설치된 규격  |
| Results    | 계산 결과         |
| Status     | 검산 상태         |
| Evidence   | 산정 근거 및 적용 기준 |

사용자가 입력한 값과 프로그램이 계산한 값은 혼합하여 저장하지 않는다.

## 3.2 부하 노드 속성

부하 노드에는 다음 정보를 입력할 수 있다.

- 정격출력 및 전기 입력전력
- 단위(kW, kVA 등)
- 정격전압
- 단상·삼상 구분
- 역률
- 효율
- 운전전류
- 정상 운전 상태
- 동시운전 그룹
- 최대부하율
- 기동전류 배수
- 기동 방식
- 기동시간

입력된 kW가 기계적 출력인지 전기적 입력인지 반드시 구분한다.

기본값은 사용자 지정 또는 명시적으로 표시된 가정값만 허용한다.

## 3.3 배선 엣지 속성

- 배선 길이(m)
- 도체 재질
- 단면적(㎟)
- 심수 및 병렬 회선 수
- 절연 종류
- 정격전압
- 포설 방식
- 주변 온도
- 집합 포설 조건
- 허용전류
- 저항 및 리액턴스
- 계산 전압강하
- 열적 허용조건

길이는 수동 입력을 기본으로 하며, 향후 CAD에서 추출한 실제 경로 길이를 입력할 수 있다.

## 3.4 차단기 노드 속성

다음 항목을 서로 독립된 데이터로 관리한다.

- 정격전압
- 정격전류(In)
- 정격차단용량(Icu/Ics/Icn 등 해당 규격 기준)
- 장시간 과전류 보호 설정
- 단시간 보호 설정
- 순시동작 설정
- 시간-전류 특성
- 극수
- 누전보호 기능 유무
- 정격감도전류(IΔn)
- 누전 동작시간·선택차단 특성

**정격전류, 단락 차단용량, 보호장치의 실제 동작전류는 동일한 값으로 취급하지 않는다.**

# 4. 운용 모드

## 4.1 기본설계 모드

사용자가 장비 및 계통 구성을 입력하면 프로그램이 미정인 설비의 요구규격을 계산한다.

입력:

- 장비 구성
- 전원 조건
- 노드 연결 관계
- 배선 조건
- 운전 조건
- 향후 증설 계획

출력:

- 요구 수전설비 용량
- 각 노드의 전류
- 간선 및 분기회로 요구규격
- 분전반·배전반 요구조건
- 보호장치 요구규격
- 전압강하 및 접지 검토 결과

규격은 단순한 최소 숫자가 아니라 **허용 범위 및 충족해야 하는 조건의 집합**으로 제공한다.

## 4.2 검산 모드

실제 설계 또는 설치된 설비의 규격을 입력한다.

프로그램은 동일한 계산 엔진을 사용하여 요구조건을 산정한 뒤 실제값과 비교한다.

검산 대상:

- 기존 설계도
- 설비 구성표
- 차단기 정격
- 케이블 규격
- 분전반 용량
- 수전설비 사양
- 접지계통 및 보호장치 구성

검산 결과에는 계산값, 실제값, 차이, 적용 근거를 함께 출력한다.

## 4.3 혼합 모드

기존 설비에 새로운 장비를 추가하는 경우를 지원한다.

기존 설비의 규격은 고정값으로 유지하고 신규 부하를 연결하여 변경된 요구조건을 계산한다.

사용자는 어느 설비가 병목이 되는지 확인할 수 있어야 한다.

# 5. 전기계산 엔진

## 5.1 연산 원칙

하나의 계통 그래프에 대해 여러 종류의 계산을 수행한다.

기본 계산 흐름:

**상향 계산** — 부하 → 회로 → 분전반 → 배전반 → 수전설비

**하향 계산** — 전원 조건 → 계통 전압 및 임피던스 → 보호조건 → 말단 장비

연산 사이에 상호의존성이 존재하면 수렴 조건을 가진 반복계산을 사용한다.

각 계산 결과는 입력값, 계산방법, 적용 기준을 기록한다.

## 5.2 부하 계산

단상 및 삼상 교류계통을 지원한다.

주요 계산:

- 유효전력(P)
- 무효전력(Q)
- 피상전력(S)
- 역률
- 정상운전 전류
- 최대 동시운전 부하
- 상별 부하

역률이 서로 다른 부하의 경우 단순히 피상전력을 더하는 대신 유효전력과 무효전력을 합산해 계산한다.

단순 정격 합계와 동시운전 조건을 반영한 최대수요전력을 별도로 표시한다.

## 5.3 전선 규격 산정

각 배선 구간에 대해 다음 항목을 계산한다.

1. 설계 부하전류
2. 기준 허용전류
3. 설치·온도·집합 조건에 따른 보정
4. 경로별 전압강하
5. 단락 시 열적 내량
6. 보호장치와 전선의 적합성

여러 조건을 동시에 만족하는 전선 규격의 후보를 산출한다.

## 5.4 전압강하 계산

전원에서 부하까지의 실제 경로를 따라 전압강하를 계산한다.

각 배선의 저항과 리액턴스, 부하전류, 역률을 반영한다.

출력:

- 구간별 전압강하
- 전체 경로 전압강하
- 부하단 예상전압
- 적용 허용기준 대비 결과

CAD 길이가 없으면 사용자가 입력한 추정 길이를 사용하고 해당 결과를 추정 계산으로 표시한다.

## 5.5 동시운전 시나리오

사용자는 장비의 운전 상태를 설정할 수 있다.

예시: 모터 A: ON / 모터 B: ON / 모터 C: ON / 기타 부하: OFF

시스템은 해당 운전 상태에서 각 노드와 배선에 흐르는 전류를 계산한다.

가능한 동시운전 조합과 운전 제약조건을 고려하여 최대부하를 평가한다.

장비가 많을 때는 불필요한 전체 조합 나열을 피하고 제약조건 기반 탐색을 사용한다.

## 5.6 모터 기동 계산

다음 요소를 반영한다: 기동전류, 기동시간, 기동 방식, 기존 운전 부하, 기동 시 전압강하, 차단기 동작특성.

모터 기동전류가 차단기 정격전류보다 크다는 이유만으로 부적합 판정하지 않는다.

기동전류·지속시간·보호장치 특성을 함께 비교한다.

## 5.7 단락전류 계산

전원 임피던스, 변압기 임피던스, 케이블 임피던스 등 계통 정보를 이용한다.

주요 기능:

- 노드별 예상 단락전류 계산
- 최대·최소 고장전류 검토
- 차단기 차단용량 비교
- 고장전류에 대한 보호장치 동작 검토

필요한 전원 임피던스 등의 정보가 없으면 계산 결과를 확정값으로 표시하지 않는다.

## 5.8 보호협조 검토

상위·하위 차단기의 보호 특성을 비교한다.

검토 내용: 과부하 보호, 단락 보호, 선택차단 가능성, 고장 시 차단 범위, 상하위 보호장치 간 동작시간 관계.

보호협조가 확인되지 않은 구간은 '검토 필요'로 표시한다.

## 5.9 열적 검토

전선의 허용전류와 포설조건에 따른 보정, 단락 시 열적 내량을 검토한다.

차단기의 정격뿐 아니라 도체와 보호장치 간의 보호조건 충족 여부를 판정한다.

## 5.10 접지·누전보호

다음 항목을 지원한다: 계통 접지 방식, PE 도체 연결 관계, 보호도체 요구규격, 접지 고장전류 경로, 자동전원차단 조건, 누전보호장치의 적합성, 등전위본딩 연결 관계.

접지 방식과 설치 조건에 따라 필요한 검증 규칙을 선택한다.

## 5.11 서지보호장치

SPD의 설치 위치와 전기적 조건을 검토한다.

검토 속성: SPD 유형, 최대연속사용전압(Uc), 전압보호수준(Up), 방전전류 관련 정격, 상위 보호장치와의 적합성, 접지 및 연결 조건.

SPD 설치 필요 여부는 계통 및 설치조건에 따라 판정한다.

## 5.12 수전용량 검토

계통에서 계산된 최대수요전력과 피상전력을 구분한다.

수전설비 및 변압기의 요구용량을 산출하고 실제 선정 규격과 비교한다.

한전 계약전력은 별도 항목으로 관리하며, 적용 계약종별·산정조건에 따라 검토한다.

**계약전력, 최대수요전력, 변압기 정격용량을 동일한 개념으로 처리하지 않는다.**

# 6. 설계 적합성 판정

## 6.1 기본 비교 구조

각 노드는 다음 세 가지를 별도로 보유한다.

- **Required — 계산 요구조건:** 현재 입력된 설비 및 운전 조건을 충족하기 위해 필요한 성능.
- **Installed — 설계·설치된 실제 규격:** 설계자가 선택했거나 현장에 설치된 장치의 성능.
- **Justification — 선정 근거:** 미래 증설, 특정 운전 조건, 장비 표준화 등 요구조건보다 큰 규격을 선택한 이유.

## 6.2 판정 상태

| 상태      | 의미             |
| ------- | -------------- |
| PASS    | 검증된 요구조건 충족    |
| FAIL    | 요구조건 불충족       |
| REVIEW  | 추가 설계 근거 확인 필요 |
| UNKNOWN | 계산 필수정보 부족     |
| N/A     | 해당 검증 대상 아님    |

단순히 설계용량이 계산 요구량보다 크다는 이유로 FAIL 판정하지 않는다.

## 6.3 여유율

사용자는 설비 정격 대비 사용 비율을 확인할 수 있어야 한다.

```
분전반 A
정격전류: 500A
최대 예상전류: 350A
사용률: 70%
여유율: 30%
```

단, 정격전류 기준 여유율은 하나의 지표이며 차단기 동작특성, 전선 보호조건 등의 적합성을 대체하지 않는다.

## 6.4 병목 탐지

어떤 운전 시나리오에서 계통의 특정 설비가 허용조건을 초과하면 해당 노드를 표시한다.

```
수전설비: PASS
   │
메인 배전반: PASS
   │
분전반 A: FAIL
   │
장비 1, 2, 3
```

출력: 문제가 발생한 노드, 초과된 조건, 해당 조건을 발생시킨 부하, 연결 경로, 검토가 필요한 설비규격.

# 7. 사용자 인터페이스

## 7.1 그래프 에디터

사용자는 노드를 생성하고 선으로 연결하여 전력계통을 구성할 수 있다.

지원 기능: 노드 추가·삭제, 연결 생성·수정, 속성 입력, 그룹 생성, 분전반·배전반 접기/펼치기, 노드별 계산 결과 확인, 문제 발생 경로 강조, 설계 모드와 검산 모드 전환.

전기적으로 성립하지 않는 연결은 오류 또는 검토 대상으로 표시한다.

## 7.2 노드 상세 화면

노드를 선택하면 다음 정보를 표시한다.

1. 설비에 대한 쉬운 설명
2. 사용자 입력값
3. 계산된 요구조건
4. 실제 설계규격
5. 적합성 판정
6. 선정 근거
7. 설계자에게 확인할 질문

전문 용어에는 짧은 설명을 제공한다.

## 7.3 설명 및 질문 생성

사용자가 전문적인 계산식을 몰라도 결과를 이해할 수 있도록 설명한다.

예시: **"현재 최대 예상전류는 350A이고 설계된 배전반의 정격은 500A입니다. 현재 조건에 대한 사용률은 70%입니다. 향후 증설을 고려한 선정인지 확인할 수 있습니다."**

제안 질문: "500A를 선정한 이유가 향후 증설 때문인가요? 그렇다면 추가 예정 부하는 얼마인가요?"

질문은 계산 결과와 실제 입력값에 근거하여 생성한다.

필수정보가 없는 경우는 설계 오류라고 단정하지 않고 필요한 정보를 묻는다.

# 8. 계산 결과의 추적 가능성

모든 계산 결과는 역추적할 수 있어야 한다.

예를 들어 사용자가 배전반 정격 500A의 근거를 확인하면 다음 정보가 제공된다.

```
[배전반 500A]
      │
  요구전류 350A
      │
┌─────┴─────┐
│           │
분전반 A    분전반 B
 220A        130A
│           │
장비별       장비별
부하         부하
```

실제 계산에서는 상별 전류, 역률, 동시운전 조건 등을 반영한 결과를 사용한다.

각 계산 결과에 다음 정보가 연결되어야 한다: 참조한 입력 노드, 사용한 계산식 또는 계산 절차, 적용 규격과 버전, 가정한 운전 조건, 계산 결과 및 단위, 사용자 수동 변경 이력.

이를 통해 설계값이 달라진 이유를 확인할 수 있다.

# 9. 소프트웨어 아키텍처

## 9.1 구성 요소

```
[그래프 UI]
    │
    ▼
[계통 데이터 모델]
    ├── 노드 및 엣지 저장
    ├── 계층 및 연결 검증
    ├── 운전 시나리오
    ▼
[결정론적 계산 엔진]
    ├── 부하·전류 계산
    ├── 전압강하 계산
    ├── 배선·열적 검토
    ├── 단락전류 계산
    ├── 보호협조 검토
    └── 접지·보호 검토
    ▼
[규격·판정 엔진]
    ├── 요구조건 산출
    ├── 실제 규격과 비교
    ├── 병목 탐지
    └── 정보 부족 식별
    ▼
[설명 및 보고서 엔진]
    ├── 검산 결과
    ├── 설계 근거
    └── 사용자 질문
```

## 9.2 계산 규칙

- 동일한 입력과 동일한 기준 버전은 동일한 결과를 생성해야 한다.
- 단위 변환은 중앙에서 관리한다.
- 미입력값과 0을 구별한다.
- 명시되지 않은 동시사용률이나 기동 조건을 임의 확정하지 않는다.
- 계산 모델이 지원하지 않는 계통을 임의로 단순화해 PASS 처리하지 않는다.
- 노드 변경 시 의존 관계에 있는 계산 결과를 갱신한다.
- 계산 엔진은 특정 제조사 제품 데이터에 종속되지 않는다.

## 9.3 적용 기술 기준

국내 설비 검증을 기본으로 하며 다음 기준을 참조할 수 있는 구조로 구현한다.

- 한국전기설비규정(KEC)
- 적용 가능한 IEC 전기설비 및 보호 관련 표준
- IEC 60909 계열 단락전류 계산 기준
- 한전 전기공급 및 계약전력 관련 기준

판정 규칙마다 적용 기준의 명칭, 버전, 해당 근거를 기록한다.

규정 데이터와 계산 엔진의 프로그램 코드는 분리한다.

원문 비고: KEC 저압설비·보호·접지 체계를 기준으로 규칙 데이터를 분리한다(대한전기협회 KEC 공식 자료에 개정 이력이 공개되어 있어 버전 관리 필요). 단락전류 계산 참조 기준으로 IEC 60909-0:2026(원문 기재: 2026년 7월 발행)을 명시한다.

가장 중요한 아키텍처 결정: **설계용 계산 엔진과 검산용 계산 엔진을 따로 만들지 않는다.** 동일한 그래프에서 계산된 요구조건과 실제 설계값을 비교해 두 목적을 모두 달성한다.

# 11. 구현 단계

## Phase 1 — 핵심 그래프 및 기본 검산

노드·엣지 편집, 계층적 분전반 구조, 단상·삼상 부하 입력, 부하 합산 및 전류 계산, 동시운전 시나리오, 분전반·배전반 사용률, 경로별 전압강하, 상별 부하 불평형, 요구규격과 실제값 비교, 근거 설명 및 질문 출력.

**완료 기준:** 비전문가가 장비를 연결하여 전력계통의 기본적인 용량 적합성을 검산할 수 있다.

## Phase 2 — 보호 및 계통 해석

배선 허용전류 및 보정, 단락전류 계산, 보호장치 차단용량 검증, 모터 기동 해석, 보호협조 검토, 도체 열적 내량, 누전보호 및 SPD 요구조건.

**완료 기준:** 정상 운전뿐 아니라 지정한 기동·고장 조건에서 주요 계통의 보호 요구사항을 검토할 수 있다.

## Phase 3 — 접지 및 통합 검산

접지계통 모델, PE 및 등전위본딩 연결, 접지 고장 보호 검토, 수전설비 요구용량 종합, 설계 변경 영향 분석, 전체 계통 검산 보고서.

**완료 기준:** 정의된 범위의 전력계통에 대해 기본설계와 기존 설계 검산을 하나의 그래프에서 수행할 수 있다.

# 12. 최종 출력물

- **A. 계통 구성도** — 노드 그래프 기반의 전력계통 연결 구조.
- **B. 설비 요구규격표** — 각 노드와 엣지의 전기적 요구조건.
- **C. 설계 검산표** — 설계값과 계산값 비교, 판정 결과.
- **D. 운전 시나리오 분석표** — 동시운전·기동 조건별 계통 사용률 및 병목.
- **E. 설계 근거 분석표** — 요구규격, 선정규격, 여유율 및 추가 선정 근거.
- **F. 발주자 검토 질문서** — 사용자가 설계자에게 확인할 수 있는 구체적 질문과 그 계산 근거.

보고서는 노드 ID를 기준으로 그래프의 해당 위치와 연결되어야 한다.

# 13. 최종 설계 원칙

본 프로그램은 특정 전기설비 제품을 추천하거나 전기공사 비용을 산정하기 위한 도구가 아니다.

프로그램은 **전력계통의 논리적 구성과 그 구성에 필요한 전기적 조건을 계산하고 검산하는 시스템**이다.

설계자는 프로그램에서 계산한 요구조건을 바탕으로 실제 제품을 선정하고 시공 상세설계와 적산을 수행한다.

발주자는 같은 프로그램을 이용해 설계자의 선정 결과를 독립적으로 검산하고, 선정 근거를 확인할 수 있다.

### 최종 정의

**"전기 비전문가도 노드 그래프를 이용하여 전력계통을 구성하고, 시스템에 필요한 전기적 규격을 계산하며, 기존 설계의 타당성과 선정 근거를 독립적으로 검증할 수 있는 결정론적 전기설계·검산 소프트웨어."**

**본 프로젝트의 최우선 목표는 설계의 자동화가 아니라 설계 근거의 가시화와 검증 가능성 확보이다.**
