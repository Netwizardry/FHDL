# EHDL SPEC v0.1 검토 (구현 착수 전)

> 대상: [SPEC_v0.1.md](SPEC_v0.1.md) · 작성 2026-10-30 · 상태: **D1~D4 확정(2026-10-30, 모두 권장안), S1~S12 제안대로 반영**
> 결론: SPEC 의 원칙(결정론 엔진 1개로 설계·검산 겸용, Required/Installed/Justification 분리,
> 정보 부족 = UNKNOWN, 근거 추적)은 FHDL 구조와 잘 맞고 그대로 채택한다. 다만 구현 전에
> 정해야 할 결정 4건과 SPEC 보완 12건이 있다.

## 1. FHDL 과 맞물리는 부분 (재사용)

| SPEC | FHDL 에 이미 있는 대응 | 재사용 방식 |
|---|---|---|
| 결정론 계산 + 재현성 | parse → semantic → solve → report 파이프라인, AnalysisResult 예외 없이 반환 | 같은 파이프라인 구조 |
| Required vs Installed | 관경 `auto`(요구) vs 지정값(설치), Auto-sizing | 개념 확장(조건 집합) |
| Evidence / 추적성 | provenance(formula_id), 진단 코드 체계(SYN/SEM/NET/CAL/WRN) | 진단·근거 모델 공유 |
| UNKNOWN / 정보 부족 | `has_xy` 처럼 "미입력 ≠ 0" 구분, SEM009 | 원칙 그대로 |
| 그래프 편집 | 토폴로지 뷰어 + Inverse Sync(DSL 역반영), 명령 콘솔 | GUI 셸·패널 공유 |
| 보고서 | CSV/JSON 리포트, PDF(Qt) 렌더러 | 렌더러 공유 |
| 시작 화면 | `domains.py` 에 EHDL 등록(준비 중) | window 지정 후 활성화 |

## 2. 결정 (사용자 확정 2026-10-30)

| 결정 | 확정 |
|---|---|
| D1 진실원 | DSL 텍스트 `main.ehd` + 그래프 Inverse Sync |
| D2 규정 데이터 | 규칙 파일(출처·조항·버전) + 사용자 확인, 미확인 규칙 판정 = REVIEW — **원문 9종 DB화·대조 완료([KB.md](KB.md)): 8개 규칙 확인, 설비불평형률 한도만 미확인** |
| D3 코드 위치 | `src/ehdl/` 형제 패키지 |
| D4 화면 | FHDL 셸 재사용 + 노드 상세·접기/펼치기 |

검토 당시 선택지:

- **D1. 단일 진실원** — (권장) FHDL 과 같이 **DSL 텍스트(`main.ehd`)가 진실원**, 그래프 에디터는
  Inverse Sync 로 DSL 을 고친다. 이름(Electrical *HDL*)·버전관리(diff)·재현성(원칙 3)에 유리.
  대안: 그래프 JSON 파일을 진실원으로(그래프 편집이 1차, DSL 없음).
- **D2. 기준(규정) 데이터 출처** — KEC·IEC 60364-5-52 허용전류 표·보정계수·전압강하 허용치·
  보호도체 표, IEC 60909 계수, 한전 계약전력 기준은 **규범 데이터라 임의로 만들 수 없다**
  (원칙 7·9.2). (권장) 규정 데이터를 버전 붙은 별도 파일(`ehdl/rules/*.json`, 출처·조항·버전
  필드 필수)로 두고, ① 물리 상수로 정해지는 값(도체 저항률·온도계수)은 내가 근거와 함께 넣고,
  ② 표 값(허용전류·보정계수·허용 전압강하 %)은 사용자가 원문(KEC 해설서 등)으로 확인·제공한다.
  확인 전 항목은 규칙 상태 `unverified` 로 두고 그 규칙의 판정은 PASS 가 아니라 REVIEW 로 낸다.
- **D3. 코드 위치** — (권장) 형제 패키지 `src/ehdl/`(엔진·GUI 비의존) + `src/ehdl/gui/`.
  FHDL 과 겹치는 기반(진단 모델·Inverse Sync 편집기·로그 콘솔·리포트 렌더러)은 처음엔 import 로
  쓰고, 두 분야에서 실제로 공유가 확인된 것만 나중에 공통 모듈로 뺀다.
- **D4. Phase 1 화면 범위** — (권장) FHDL 메인 창 셸(에디터·그래프·결과·진단·콘솔)을 재사용하고
  노드 상세 패널(SPEC 7.2 의 7개 항목)과 분전반 접기/펼치기를 추가. 계통 구성도(산출물 A)는
  그래프 뷰 내보내기로 충족(CAD 아님 — 아이소메트릭 CAD 는 기본형 완성 후).

## 3. SPEC 보완 사항 (제안 — 반대 없으면 이대로 구현)

| # | 위치 | 문제 | 제안 |
|---|---|---|---|
| S1 | 3.2 / 5.2 | 상별 불평형을 요구하지만 단상 부하의 **접속 상(L1/L2/L3)** 속성이 없음 | 부하에 `phase = L1\|L2\|L3\|L1L2…` 추가. 단상 부하에 없으면 불평형 판정 UNKNOWN |
| S2 | 3.2 | kW 가 기계 출력인지 전기 입력인지 구분 필수 — 표기 방법 미정 | `rating = 37kW; rating_basis = output\|input;` output 이면 `efficiency` 필수(없으면 UNKNOWN, 가정 금지) |
| S3 | 5.5 / TC-02 | "사용 가능한 전력 한도"가 어느 노드의 무슨 속성인지 미정 | 전원·수전 노드의 `limit_kw`/`limit_kva`(Installed 성격). 초과 시 FAIL + 원인 시나리오 |
| S4 | 5.2 / 9.2 | 수용률(demand factor)을 쓸 수 있는지 불명확(임의 확정 금지 원칙) | 시나리오(ON/OFF)가 기본. 수용률은 사용자가 근거와 함께 입력할 때만 적용하고 결과에 "수용률 적용" 표시 |
| S5 | 6.1 | Required 를 "조건 집합"으로 — 표현 형식 미정 | Requirement = (항목, 비교 연산, 값, 단위, 근거 규칙 ID, 기준 버전). 예: `I_n ≥ 182.3A [KEC …]` |
| S6 | 6.2 | 여러 검사의 상태를 노드 상태로 합치는 규칙 없음 | 우선순위 FAIL > UNKNOWN > REVIEW > PASS > N/A, 노드 상세에는 검사별 상태를 모두 표시 |
| S7 | 6.2 / TC-05 | "과대 규격"의 REVIEW 기준값 미정 | 사용률 임계(예: 50% 미만)를 규정이 아닌 **사용자 설정값**으로 두고, 근거(Justification) 입력 시 PASS |
| S8 | 2.2 | 계층 포트 의미(전압·상·전류 방향) 미정 | Phase 1: 컨테이너당 입력 포트 1·출력 포트 n(방사형). 다중 포트는 Phase 3 |
| S9 | 2.1 예시 | 변압기가 Phase 1 범위인지 불명확 (전압 변환이 있으면 전류·전압강하 기준이 바뀜) | Phase 1 은 변압기를 **전압 경계**로만 처리(정격 kVA·전압비·사용률). 변압기 내부 전압강하·임피던스는 Phase 2(단락 계산과 함께) |
| S10 | 5.4 | 전압강하 식·허용치 출처 미정 | 식: ΔV = k·I·L·(R cosφ + X sinφ), k=2(단상)/√3(삼상). R 은 저항률·온도 보정으로 계산, X 는 입력 또는 규칙 데이터. 허용치는 D2 규칙 데이터 |
| S11 | 9.3 | IEC 60909-0:2026 발행 정보 — 내가 확인하지 못함 | 규칙 데이터의 기준 버전 필드에 사용자 지정 값으로 기록, Phase 2 착수 시 원문으로 확인 |
| S12 | 12 | 보고서 형식 미정 | JSON(기계 판독) + CSV(표) + PDF(사람용, 노드 ID 로 그래프와 연결) |

## 4. Phase 1 작업 분해 (D1~D4 권장안 기준)

| 단계 | 내용 | 검증 |
|---|---|---|
| P1-1 | 데이터 모델: Node/Edge, Parameters·Installed·Justification(입력) ↔ Required·Results·Status·Evidence(계산) 분리, 계층(Parent·포트) | 모델 단위 테스트 |
| P1-2 | EHDL DSL(`main.ehd`) 문법·파서·의미 분석(단위 정규화, 미입력≠0, 진단 코드 ESYN/ESEM) | 파서 테스트 |
| P1-3 | 규칙 데이터 체계(`ehdl/rules/`, 출처·버전·`unverified` 상태) | 규칙 로더 테스트 |
| P1-4 | 부하 계산: P·Q·S·역률·전류(단상/삼상), 상향 집계(P·Q 합산), 계층 집계 | TC-01, TC-09 |
| P1-5 | 운전 시나리오 + 최대 동시부하(제약 기반 탐색), 전원 한도 | TC-02 |
| P1-6 | 사용률·여유율, Required↔Installed 판정, 병목 경로 | TC-03(허용전류는 입력값), TC-05 |
| P1-7 | 경로별 전압강하, 상별 불평형 | TC-06, TC-08(부분) |
| P1-8 | 설명·질문 생성(계산값·입력값 근거, 단정 금지 문구 규칙) | TC-05 문구 |
| P1-9 | GUI: 시작 화면 활성화, 그래프 에디터(접기/펼치기), 노드 상세 7항목, 모드 전환 | GUI 스모크 |
| P1-10 | 보고서 B·C·D·E·F (JSON/CSV/PDF) + 계통 구성도(A, 그래프 뷰) | 보고서 테스트 |

TC-04(모터 기동)·TC-07(단락)은 Phase 2, TC-03 의 허용전류 **산정**(표·보정)은 D2 데이터 확보 후 Phase 2.
