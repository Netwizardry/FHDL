# EHDL 계산·판정 엔진

> 코드: `src/ehdl/engine.py`(계산) · `judge.py`(판정·병목) · `judge2.py`(보호) · `judge3.py`(접지·수전) ·
> `impact.py`(변경 영향) · `explain.py`(설명·질문) · `pipeline.py`
> 규칙: `src/ehdl/rules/kec_lv.json` (원문 대조 — [KB.md](KB.md)) · 지식 DB: `src/ehdl/kb/`

## 파이프라인

```
Parse(ESYN) → Semantic(ESEM) → 토폴로지(ENET) → 부하·시나리오(ESCN) → 상향 집계·전압강하 → 판정 → 설명·질문
```
같은 입력·같은 규칙 버전은 같은 결과(SPEC 9.2). 예외 없이 `EResult` 를 돌려준다. 설계·검산 엔진은 하나다 —
요구조건(Required)을 계산하고, 실제 규격(Installed)이 있으면 비교한다.

## 계산

| 항목 | 방법 |
|---|---|
| 부하 전력 | `P` = 입력 kW 또는 출력 kW ÷ 효율 (kVA 면 S·pf), `Q = P·tan(acos pf)` — 누락 입력이 있으면 지어내지 않고 집계에서 빼 `incomplete` 로 표시 |
| 상 배분 | 삼상 S/3 씩, 상-중성 단상 그 상, 선간 단상 두 상에 S/2 |
| 시나리오 | `rated`(정격 합계, 참고) · `normal`(state) · `max_demand`(그룹 `max_on` 제약 내 — 큰 부하부터 고르는 제약 기반 선택, 전체 조합 나열 없음) · 사용자 `scenario` |
| 상향 집계 | 유효·무효전력 각각 합산(피상전력 단순합 아님), 상별 복소 피상전력 합 |
| 전류 | 최대 상전류 `max|S_k| ÷ V_LN` (단상 상 미지정이 있으면 `|S| ÷ (√3·V)` 평형 가정 추정) |
| 전압 | 전원 선간전압, 변압기 이후 2차 전압 |
| 전압강하 | KS C IEC 60364-5-52 부속서 G: `u = b(ρ1·L/S·cosφ + λ·L·sinφ)·IB`, `Δu% = 100·u/U0`. b = 1(3상)·2(단상), 불평형률 ≥ 30% 3상 회로는 b = 2. ρ1 = Cu 0.0225·Al 0.036 Ω·mm²/m, λ 기본 0.08 mΩ/m. 전원(또는 변압기 2차)부터 경로 누적 |

## 판정

| 검사 | 요구조건 | 기준 |
|---|---|---|
| `source_limit` | 운전 부하 P(또는 S) ≤ 사용 가능 한도 | 정의 |
| `transformer_rating` | S ≤ 정격 kVA (변압기 손실 제외) | 정의 |
| `board_rating` | 최대 상전류 ≤ 반 정격전류 | 정의 |
| `breaker_load` | IB ≤ In | KEC 212.4.1 |
| `cable_ampacity` | IB ≤ IZ (입력 또는 지식 DB 표 B.52.2~5, 기준 조건) | KS C IEC 60364-5-52 |
| `breaker_cable_coord` | In ≤ IZ (차단기 바로 아래 배선) | KEC 212.4.1 식 212.4-1 |
| `voltage_drop` | 경로 Δu ≤ 허용치(수전 형태·조명/기타·100 m 초과 가산) | KEC 232.3.9 표 232.3-1 |
| `unbalance` | 단상 설비불평형률 ≤ 30% | 내선규정 — **원문 미제공(미확인)** |
| `sizing_rationale` | 사용률 < `review_below` 이고 선정 근거 없음 → 질문 | 프로그램 설정 |
| `breaking_capacity` | 정격차단용량 ≥ 설치 점 Ik''max (전원 측 후비보호 가능하면 REVIEW) | KEC 212.5.5의 1 |
| `thermal` | S ≥ Is,min·√tn / k (권장 ×1.25), tn < 0.1 s 는 제조사 통과 I²t | KEC 212.5.5의 2 식 212.5-1, 검사·점검 기준 240절 |
| `selectivity` | In 상위 > In 하위, 하위 설치 점 Ik''max < 상위 순시 하한 — 아니면 REVIEW(제조사 선택차단표) | KEC 표 212.3-3 |
| `motor_start_vd` | 기동 순간 단자 전압강하 ≤ `motor_start_vd_limit` (없으면 값+질문) | 검사·점검 기준 240절, KEC 232.3.9의 2 |
| `motor_start_protection` | Ims < 순시 하한·In 이고 Ims/In < δ(tb = 1.5·tm) | KEC 표 212.3-3, KEC 시공 가이드북 |
| `rcd_socket` | 일반인 사용 20 A 이하 콘센트 → 전원 측 누전차단기, 감도 ≤ 30 mA | KEC 211.2.3의 4 (감도 조항은 미확인) |
| `spd` | SPD 유무·선정 근거 질문 (Uc·Up 수치 기준은 제공 자료에 없음) | KEC 153.1.4 |
| `sc_min_trip` | 보호 구간(다음 차단기까지) 끝의 Ik''min ≥ 순시 상한 × In — 아니면 장한시 영역 동작이라 열적 내량의 trip_time 가정 불성립 → REVIEW·질문. 차단 범위(정전되는 부하 수) 표시 | KEC 표 212.3-3, SPEC 5.7·5.8 |
| `cable_size` | **전선 규격 산정**(아래) — 실제 단면적 없으면 요구값·후보만(N/A), 있으면 비교 | SPEC 5.3 |
| `load_input` | 부하 필수 입력 | — |

판정 정책 (SPEC 6.2):
- 대상마다 **가장 불리한 시나리오**(max_demand 또는 normal + 사용자 시나리오)로 판정, `rated` 는 참고.
- 입력 부족: 확인된 부하만으로 이미 초과면 FAIL(빠진 부하는 더할 뿐), 아니면 **UNKNOWN** + 필요한 입력 목록.
- 추정 입력(길이 estimate·상 미지정): 충족이어도 **REVIEW**. 기준이 정한 기본값(λ)은 추정이 아니라 '기준 기본값'.
- 원문 미확인 규칙(`verified=false`): 충족 → REVIEW, 위반 → FAIL(미확인 표시).
- 정격이 요구보다 큰 것은 FAIL 이 아니다 — 사용률·여유율과 '선정 근거' 질문으로 다룬다.
- 노드 상태 = 검사 중 최악(FAIL > UNKNOWN > REVIEW > PASS > N/A).

병목(`judge.bottlenecks`): FAIL 마다 대상·초과량·운전 조건·원인 부하(기여 큰 순)·전원까지 경로·상위 설비 상태.

## Phase 2 — 보호 및 계통 해석

### 단락전류 (`shortcircuit.py`, SPEC 5.7)

전기설비 검사·점검 기준 220.1.2 (KS C IEC 60909-0): `Ik'' = c·Un / (√3·|Zk|)` (3상 대칭, 원격 고장).

| 요소 | 최대 조건 | 최소 조건 |
|---|---|---|
| 전압계수 c (표 220-3) | 저압 1.05(+6%) / 1.10(+10%), 고압 1.1 | 저압 0.95, 고압 1.0 |
| 전원 ZQ = c·Un²/S''kQ | `sc_mva` (최소 등가 임피던스) | `sc_mva_min` (최대 임피던스) |
| 변압기 ZT = uk·Ur²/Sr | × KT = 0.95·cmax/(1+0.6·xT) **[IEC 60909 — 원문 미제공, 미확인]** | 보정 없음 |
| 배선 | R20 = ρ1/1.25 · L/S, X = λ·L | R 을 단락 온도한계(표 220-4: XLPE 250℃, PVC 160/140℃)로 환산 (α 0.004 **미확인**) |
| 전동기 | 저압 모선별 Σβ·IrM 를 등가 임피던스로 계통과 병렬(테브난) | 무시 |

전원 단락용량(`sc_mva`)·변압기 `uk` 가 없으면 그 하류는 계산하지 않고 UNKNOWN (SPEC 5.7). 단상·지락 최소 단락은 Phase 3(접지).

### 전동기 기동 (`motorstart.py`, SPEC 5.6, TC-04)

다른 부하는 판정 시나리오대로 운전하고 대상 전동기만 기동: 구간 전류 = 운전 전류 − 대상 운전 전류 + `Ims∠−θs`,
구간별 `Δu = b·L(R·Ip + X·Iq)/U0` + 변압기 `I/IrT·(uR cosφ + uX sinφ)` + 전원 임피던스. 기동전류가 정격을 넘는 것만으로는
부적합이 아니다 — 순시 트립 범위(표 212.3-3 B/C/D, 산업용 `instantaneous`)와 제조사 곡선의 tb(=1.5·tm) 동작배율 δ 로 판단.

### 전선 규격 산정 (`sizing.py`, SPEC 5.3 — 기본설계 모드의 핵심 산출)

표준 공칭 단면적(KS C IEC 60228, 1.5~630 ㎟)을 작은 것부터 대입해 조건별 최소값을 구하고 그 최댓값을 요구 단면적으로,
그 위 3개를 후보로 낸다. 지배 조건을 함께 표시한다(결과 '배선' 탭·계통 구성도 `요구 ≥ … ㎟`).

| 조건 | 식 |
|---|---|
| 허용전류·보호협조 | IZ(S) ≥ max(IB, In, I2 ÷ 1.45) — IZ 는 표 B.52.2~5 × 보정계수 (공사방법·주변 온도·집합 필요) |
| 전압강하 | 하류 부하마다: 경로의 다른 배선 강하(실제 규격) + 이 배선 Δu(S) ≤ 허용치 (변압기 2차에서 새로 시작) |
| 단락 열적 내량 | S ≥ Is,min(S)·√tn / k — 배선 끝 최소 단락전류를 후보 S 마다 다시 계산(`shortcircuit.ik_min_at_end`) |

허용전류·전압강하 조건을 계산할 입력이 없으면 UNKNOWN(필요 입력) — 계산된 조건만의 하한은 함께 보인다.
열적 내량 입력(trip_time 등)이 없으면 그 조건만 빼고 기준 기본값 메모로 남긴다. 산정 중 모델은 바꾸지 않는다.

### 허용전류 보정 (`judge._table_ampacity`)

`IZ = 표 B.52.2~5 × 주위온도(B.52.14 기중 / B.52.15 지중) × 집합(B.52.17 항 1~5 / B.52.18 지중 직매 간격) × 토양(B.52.16)`.
표 사이 값은 바로 위 값(보수적)을 쓰고 '추정'. 배치 항·간격 미입력은 항 1·접촉(보수적) 가정. 지중 덕트 집합(B.52.19)은 미이식.

## Phase 3 — 접지 및 통합 검산 (`judge3.py`, `impact.py`)

| 검사 | 요구조건 | 기준 |
|---|---|---|
| `fault_protection` (TN) | 고장전류 U0/Zs ≥ Ia. Ia = 누전차단기 IΔn 또는 순시 상한(B 5·C 10·D 20·`instantaneous` × In) | KEC 211.2.5의 6 |
| `fault_protection` (TT) | 누전차단기: RA × IΔn ≤ 50 V. 없으면 Zs(RA+RB+선로) × Ia ≤ U0 | KEC 211.2.6 |
| `it_first_fault` | RA × Id ≤ 50 V, 절연감시장치 없으면 REVIEW | KEC 211.2.7 |
| `tnc_rcd` | TN-C 계통 누전차단기 → FAIL | KEC 211.2.5의 8 |
| `pe_size` | 표 142.3-1 최소 (별도 포설 Cu 2.5/4 ㎟) | KEC 142.3.2 |
| `bonding` / `main_bonding` | 주 본딩 ≥ max(최소, 가장 큰 PE/2), Cu 25 ㎟ 상한 / 본딩 없으면 질문 | KEC 143.3.1 / 143.2 |
| `supply_summary` | 설비용량·최대수요전력(최악 시나리오)·수용률·변압기 정격·식 230-6 용량·계약전력 | 검사·점검 기준 230.4.3 / 계약전력 **미확인** |

고장루프 임피던스 `Zs = ZT + Σ(ρ1·L/S + ρ1·L/S_PE + jλL)` — 변압기 2차(또는 저압 수전 `Un²/S''k`)부터.
변압기는 Dyn 결선·영상 ≈ 정상 임피던스 가정(추정 → 충족이면 REVIEW). PE 미입력은 표 142.3-1 최소값을 가정(추정).
허용 차단시간: 보호장치 32 A 이하 분기회로는 표 211.2-1(U0 별), 그 밖(간선·32 A 초과)은 TN 5 s · TT 1 s.
고장전류가 순시 영역 아래이고 허용 시간이 1 s 이상이면 FAIL 이 아니라 REVIEW — 제조사 시간-전류 곡선으로 확인.

**설계 변경 영향** (`impact.diff(old, new)`): 같은 검사 ID 끼리 상태(악화/개선)·값(상대 0.5% 이상)·추가/삭제를 비교.
GUI 는 해석할 때마다 직전 결과와 비교해 '변경 영향' 탭·로그에 보이고, 보고서에 `baseline` 을 주면 표로 넣는다.

## 혼합 모드 · 기동 방식 · 차단기 설정 · 변경 이력

- **혼합 모드** (`mixed.py`, SPEC 4.3): `stage = new` 설비(또는 new 반·배선 아래 부하)가 있으면 시나리오 `existing`(신규 제외, 참고용)을
  만든다. 기존 설비의 용량 검사마다 신규 전·후 사용률을 비교해 '신규 부하로 초과'면 FAIL 설명·질문·병목(`new_load_caused`)에 표시.
  결과 '혼합(기존/신규)' 탭·보고서 MIXED 표. 신규 설비는 실제 규격이 없으면 요구규격(기본설계)만 나온다.
- **기동전류** (`motorstart.start_current`, 검사·점검 기준 240.3.1): C × β × 정격(C 전전압 1.0 · Y-△ 0.33 · 리액터 Tap) 또는
  전류제한 비율 × 정격(소프트스타터·인버터). 기동 전압강하·기동 보호 판정이 같은 값을 쓴다.
- **차단기 설정**: 과부하·보호협조·전선 규격 산정은 Ir(= `ir_setting` × In). `sc_min_trip` 은 순시 영역 밖이라도 Isd 이상이면
  tsd 동작으로 본다. 차단용량은 Icu(`breaking_capacity`) 로 판정하고 Ik''max > `ics` 면 REVIEW. `rated_voltage` < 계통전압 → FAIL
  (`rated_voltage`). 누전차단기 직렬은 `rcd_selectivity` — 동작 형별 시간(KESCO 검사기준 변화 표: 고속형 ≤ 0.1 s, 시연형 0.1~2 s)
  으로 상위 최소 > 하위 최대·감도 상위 > 하위를 보이고, 선택차단 요건 조항은 미확인이라 REVIEW.
- **변경 이력** (`history.py`, SPEC 8): 저장할 때마다 `<이름>.history.jsonl` 에 블록 단위 변경(추가/삭제/속성 이전→이후)·
  판정 변화 요약·판정 건수를 한 줄씩 남긴다. 결과 '변경 이력' 탭, 노드 상세 '변경 이력', 콘솔 `history [id]`, 보고서 HISTORY 표.

남은 것: 단상·지락 최소 단락전류 정밀식(IEC 60909 영상 임피던스), 다중 전원·루프 — [ROADMAP](../ROADMAP.md). 이후 아이소메트릭 CAD.
