# GUI 가이드

> 구현: `gui/main_window.py`, `gui/panels/*`, `gui/log_console.py`, `gui/library_dialog.py`.

## 시작 화면 (설계 분야 선택)

실행하면 먼저 설계 분야를 고른다(`gui/start_dialog.py`, 분야 목록 `fhdl/domains.py`).

| 분야 | 상태 |
|---|---|
| **FHDL** — 유체 설비 설계 | 사용 가능 (아래 5패널 메인 창) |
| **EHDL** — 전기 설비 설계 | 사용 가능 — [EHDL 화면](ehdl/GUI.md) |

- "다음부터 이 선택으로 바로 시작" 체크 → 다음 실행부터 시작 화면 생략(QSettings `startup/domain`).
- 명령줄: `--domain fhdl`(바로 시작), `--select`(기억 무시하고 시작 화면). 준비 중·알 수 없는 분야를 지정하면 안내와 함께 시작 화면.
- 실행 중 **파일 → 설계 분야 전환…** → 메인 창을 닫고 시작 화면으로. 시작 화면을 닫으면 종료.
- 새 분야 추가: `domains.DOMAINS` 에 항목을 넣고 `window="모듈:클래스"`, `available=True`. 메인 창이 `switch_domain_requested`·`closed` 시그널을 가지면 전환/종료가 연결된다.

## 레이아웃 (5패널 + 하단 콘솔)

```
┌──────────┬───────────── 에디터 │ [토폴로지(2.5D) | 도면] 탭 ─────┐
│ 프로젝트 ├───────────────── 결과 │ 진단 ────────────────────────┤
│ 패널     │                                                        │
├──────────┴────────────────────────────────────────────────────────┤
│ 작업 로그 콘솔 (로그 출력 + 명령어 입력줄)                          │
└────────────────────────────────────────────────────────────────────┘
```

- **프로젝트 패널**: 최근 목록, 새 프로젝트(해발·온도 입력)/열기/저장/삭제.
- **DSL 에디터**: 구문 강조, 줄번호·에러 마커, 300ms debounce 린팅, "+추가"(노드 다이얼로그)·"?문법".
- **토폴로지 뷰어**: `(x,y,z)` **아이소메트릭 2.5D** 투영 + 높이 기둥 + 바닥 격자. 노드 타입별 도형, 진단색(빨강=ERROR/주황=WARNING). 더블클릭=속성 편집, 드래그=연결 추가/삭제.
- **도면 탭**: 배관 아이소메트릭(ISO 6412-2 스타일)·평면도·정면도·계통도(P&ID)를 ISO 기호·치수·BOM·표제란과 함께 표시. [내보내기…]로 PDF·DXF·SVG·PNG·STEP. 자세히는 [DRAWING](DRAWING.md).
- **결과 뷰어**: 요약 카드 + 배관/노드 테이블(`unit_system` 따라 단위 환산), CSV 내보내기.
- **진단 패널**: 심각도별 트리, 더블클릭 시 에디터 해당 줄 이동.

## 그래프 직접 편집 (Inverse Sync)

GUI 편집이 DSL 텍스트에 역반영된다(`core/dsl_editor.py`):
- 노드 더블클릭 → 속성 편집/삭제, 배관 더블클릭 → 길이·관경·자재·피팅 편집.
- 노드 간 드래그 → 연결 추가(이미 있으면 확인 후 삭제).
- **도면 탭**: 클릭 = 선택 강조, 더블클릭 = 위와 같은 노드/배관 편집. 평면도·정면도에서 노드 드래그 → `x, y`(평면) / `x, z`(정면) 좌표 갱신 후 재해석.

## 하단 명령 콘솔 (TUI)

로그 출력 + 명령어 입력으로 GUI 작업을 키보드로 수행. 자세한 명령은 [COMMANDS](COMMANDS.md).
```
› add tank T1 z=10m         › link A B
› set T1 required_q=80lpm    › del T1     › run
```
- 명령 히스토리 ↑/↓, `help` 로 목록.

## 부품 라이브러리 관리

설정 → 부품 라이브러리 관리(Ctrl+Shift+L): 관경·재질·피팅·펌프커브·유체 **CRUD** 탭. [저장]으로 `library.db` 반영.

## 편집 보조

- **실시간 검사**: 입력을 멈추고 300 ms 뒤 구문·의미 검사(SYN/SEM)만 돌려 진단 패널·에디터 오류 줄을 갱신한다(해석 결과는 유지).
- **자동 들여쓰기**: Enter 는 현재 들여쓰기 유지(`{` 뒤면 한 단계 더), 빈 줄에서 `}` 는 한 단계 내어쓰기.
- **미저장 확인**: 창 닫기·다른 프로젝트 열기·설계 분야 전환 전에 저장/버리기/취소를 묻는다.
- **해석 중단**: 부분 결과는 표시·저장하지 않고 편집 상태(DIRTY)로 돌아간다.

## 상태 기계

IDLE → DIRTY(편집) → VALIDATING/SOLVING(해석) → SOLVED / VALIDATION_FAILED / CALC_FAILED, SAVING → SAVED. 상태 메시지는 상태바와 로그 콘솔에 표시.
