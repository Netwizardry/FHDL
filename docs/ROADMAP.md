## 1. 복합 루프망 해석 (Hardy-Cross) — 대형, 우선순위 높음

**현황**: 솔버는 트리 + 단순 병렬(DAG)만 해석한다. 루프(순환)는 `NET004`(복합 루프 경고)로 표시되고 정확히 풀리지 않는다.

**필요 작업**:
- 루프(독립 회로) 식별 — `networkx` circuit rank / cycle basis.
- 루프별 유량 보정 반복법(Hardy-Cross) 또는 전역 Newton 기반 루프 방정식.
- **구조 충돌 주의**: 현재 Pass 1(`_pass1_flow_synthesis`)은 말단 수요를 역방향 BFS로 **유일하게** 분배한다(트리 가정). 루프에서는 유량 분배가 유일하지 않으므로 Pass 1 을 "초기 유량 추정 → 루프 보정" 구조로 재설계해야 한다.
- NET004 를 경고에서 정식 지원으로 전환.

**규모**: 수백 줄 + 다수 테스트(루프 1개/다중 루프/병렬 검증). 별도 집중 세션 권장.

## 2. 수충격(Water Hammer) 정밀 해석 — 대형

**현황**: 정상상태 유속 기반 **위험 지수**(`WRN004`, `ρ·a·v/P_allow > 0.8`)만 제공. 실제 과도(압력 서지) 해석은 없다.

**필요 작업**:
- **특성선법(MOC)** 기반 시간전진 트랜지언트 솔버(별도 엔진).
- 경계 조건: 밸브 폐쇄 곡선, 펌프 트립, 탱크/저수조.
- 압력파 속도 a (재질 `wave_velocity_ms` 보유), 시간격자·관 분할.
- 결과: 최대/최소 서지 압력, 시간이력. 신규 결과 모델·표시(차트) 필요.

**규모**: 신규 엔진 모듈 + 결과/표시 확장. 별도 집중 세션 권장. (원 명세에서도 v0.2+/v0.3로 이연)
