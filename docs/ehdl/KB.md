# EHDL 지식 DB — 전기설비 기준 원문 DB화

> 코드: `src/ehdl/kb/` (빌더 `build.py`, 조회 `__init__.py`) · 규칙: `src/ehdl/rules/kec_lv.json`
> 원문: `archive/EHDL-Docs/` (사용자 제공 PDF 9종) · DB: `data/ehdl_kb.db`
> **원문 일부가 '무단전재 및 재배포 금지' 문서이므로 원문 폴더와 DB 는 저장소에 올리지 않는다**(.gitignore).
> 저장소에는 빌더 코드와, 원문과 대조한 규칙 값·조항·쪽 인용만 들어간다.

## 만들기

```bash
pip install -e .[kb]                                   # pymupdf (빌드 때만 필요)
python -m ehdl.kb.build archive/EHDL-Docs              # → data/ehdl_kb.db (약 4초)
```

DB 가 없어도 EHDL 엔진은 동작한다 — 표 조회가 필요한 판정(허용전류 자동 산정)만 UNKNOWN 이 된다.
다른 위치의 DB 는 환경변수 `EHDL_KB` 로 지정.

## 스키마

| 테이블 | 내용 |
|---|---|
| `documents` | doc_id·파일·제목·종류(regulation/standard_ref/inspection/guide/case)·발행·판·쪽수·sha256·이용 제한 문구 |
| `pages` (+ `pages_fts`) | 쪽별 원문, PDF 쪽·인쇄 쪽번호 — trigram 전문검색(한글 부분 일치) |
| `clauses` (+ `clauses_fts`) | KEC 조항: 번호(232.3.9)·제목·본문·상위 조항·깊이·쪽 |
| `tables` | 표 번호·제목·쪽 (표 232.3-1, 표 B.52.4 …) 566개 |
| `ampacity` | 표·절연(PVC / XLPE/EPR)·부하 도체 수(2/3)·재질(Cu/Al)·공사방법(A1~D2)·단면적·허용전류·도체 온도·쪽 |
| `correction` | 허용전류 보정계수 251행: 표 B.52.14(기중 주위온도)·B.52.15(지중온도)·B.52.16(토양 열저항률)·B.52.17(집합 항 1~5)·B.52.18(지중 직매 간격) |
| `rule_sources` | EHDL 규칙 ID ↔ 원문 문서·조항·쪽·발췌 (22개) |

```python
from ehdl.kb import KB
kb = KB()
kb.clause("232.3.9")["title"]            # '수용가 설비에서의 전압강하' (p.137)
kb.subclauses("212.4")                   # 212.4.1 ~ 212.4.4
kb.search("수용가 설비에서의 전압강하")    # 전문검색 → 문서·쪽·발췌
kb.ampacity("XLPE", 3, "Cu", "C", 35)    # 147 A (표 B.52.5, p.558)
```

허용전류 표는 숫자 열을 "단면적이 커질수록 증가"하는 구간으로 나눠 공사방법 열에 배정하고, 열 개수·길이를
검증한다(알루미늄 D2 는 16㎟부터라 11행). 값 일부는 원문 표를 렌더링해 눈으로 대조했다
(`tests/test_ehdl_kb.py`: B.52.2 A1 1.5㎟ 14.5 A, B.52.5 C 35㎟ 147 A·95㎟ 278 A·B1 300㎟ 514 A 등).

## 아직 DB 화하지 않은 것

- 지중 덕트 집합 표 B.52.19, 케이블 트레이 B.52.20~21 — 원문 검색만 가능.
- KS C IEC 60909-0 원문 (KT·온도계수 확인용), 내선규정 — 미제공.
- 무기물 절연 표 B.52.6~B.52.13 — 조항 원문은 검색 가능.
- 한전 기본공급약관(계약전력) — 원문 미제공.
- 내선규정(설비불평형률 등) — 원문 미제공.
